# Kosmora

Kosmora is an AI engineer for your desktop: an agent that reads, edits and runs your project while you stay in control.
More at **https://kosmora.dev**.

## Download

Get the latest Windows installer from the [Releases page](https://github.com/be59okuz/kosmora-release/releases/latest), or directly:

**[Kosmora-Setup.exe](https://github.com/be59okuz/kosmora-release/releases/latest/download/Kosmora-Setup.exe)**

Windows 10 / 11 (64-bit). Free preview; you bring your own model API key.
